- STEP 3: Designed CultivatorFlightNavigator algorithm (stateless utility class in dev.ergenverse.entity.control):
  1. Compute straight-line horizontal direction (nx, nz) to target.
  2. Edge case: if horizMag < 0.001 (directly above/below target), return vertical-only velocity (signum(toTarget.y) * speed * 0.5). No horizontal obstacle possible.
  3. Ray-cast forward LOOKAHEAD=3.0 blocks at 3 height samples (0.5, 1.0, 1.5 above entity Y). If ANY sample hits a solid block (BlockState.isSolidRender — consistent with FlightMoveControl), the path is blocked.
  4. If NOT blocked: return direct velocity (nx*speed, ny, nz*speed) where ny eases toward desiredY (caller-computed cruise altitude). This is the CRON-130 behavior preserved for the common clear-path case.
  5. If blocked: probe perpendicular dodge directions. Left perpendicular = (nz, -nx) [90° CCW rotation]; right perpendicular = (-nz, nx). Probe at DODGE_PROBE_DIST=2.0 blocks at chest height (Y+1.0). If exactly one is clear, dodge that way. If BOTH are clear, use a deterministic per-cultivator bias: goLeft = (cultivator.getId() & 1) == 0. This prevents oscillation — every cultivator has a stable 'handedness' for dodging.
  6. Dodge velocity: perpendicular * DODGE_SPEED_SCALE (0.7) + forward * DODGE_FORWARD_BIAS_SCALE (0.2) + upward * DODGE_UPWARD_BIAS_SCALE (0.15). The forward bias ensures the cultivator still makes progress toward the target while dodging. The upward bias helps clear the obstacle.
  7. If NEITHER dodge is clear: vault upward. Forward velocity * VAULT_FORWARD_SCALE (0.3) + upward velocity * VAULT_SPEED_SCALE (0.8). Strong upward impulse to clear the obstacle.
  8. Return immutable SteerResult(velocity, blocked, dodgedLeft, dodgedRight, vaulted) — caller uses flags for stuck detection + logging.
