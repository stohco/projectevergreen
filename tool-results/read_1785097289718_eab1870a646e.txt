   109→ *       inherits the Suzaku Son status (Ch 443-450+) BEFORE Wang Ping's
   110→ *       redemption (Ch 680+). The inheritance is a strict prerequisite.</li>
   111→ *   <li><b>Player has exactly 1 FLESH strand AND 1 SOUL_GUARD strand in inventory.</b>
   112→ *       CRON-118 canon correction: the prior CRON-117 implementation
   113→ *       checked the bead's {@code isLiMuwanRevived} flag as a proxy for
   114→ *       "Wang Lin has the prerequisites to channel Ling Tianhou's sword
   115→ *       qi". This was chronologically INVERTED — Li Muwan is revived at
   116→ *       the END of the novel (Wang Lin at 踏天境), which is FAR AFTER
   117→ *       Wang Ping's redemption (Wang Lin at 问鼎). CRON-118 removes the
   118→ *       Li Muwan revived proxy and replaces it with the canon-faithful
   119→ *       Sword Qi Strand item (obtained from Ling Tianhou at the Da Luo
   120→ *       Sword Sect, CRON-118).<br>
   121→ *       CRON-122 canon-faithful strand-type differentiation: the prior
   122→ *       CRON-118 check was "≥2 sword qi strands of any type". This
   123→ *       incorrectly accepted 2 strands of the same type. CRON-122
   124→ *       tightens the check to "exactly 1 FLESH + 1 SOUL_GUARD strand",
   125→ *       matching the Baidu Baike 王平 entry: "一道化作王平的血肉之躯，
   126→ *       另一道守护其魂魄" (one strand became Wang Ping's fleshly body,
   127→ *       the other guarded his soul). Both functions are canon-required;

   734→     *   <li><b>AMETHYST_BLOCK_CHIME at both ends</b> — the crystalline
   735→     *       tone of sword qi (Ling Tianhou is the Sword Venerable; his
   736→     *       sword qi manifests as a crystalline tone).</li>
   737→     *   <li><b>BELL at midpoint</b> — the formal moment of redemption
   738→     *       (like a temple bell, mirroring MuBingmeiAcceptanceEvent).</li>
   739→     *   <li><b>PLAYER_LEVELUP at Wang Ping</b> — the bright ascending
   740→     *       tone of new life (a child's first breath).</li>
   741→     * </ul>
   742→     *
   743→     * @param level     the server level
   744→     * @param crystalPos the Crystal's block position (sword-qi source)
   745→     * @param wangPing  the materialized Wang Ping entity (sword-qi destination)
   746→     */
   747→    private static void spawnRedemptionEffects(ServerLevel level,
   748→                                                 BlockPos crystalPos,
   749→                                                 EntityCultivator wangPing) {
   750→        double crystalX = crystalPos.getX() + 0.5;
   751→        double crystalY = crystalPos.getY() + 1.0;  // chest height
   752→        double crystalZ = crystalPos.getZ() + 0.5;
   753→
   754→        double bodyX = wangPing.getX();
   755→        double bodyY = wangPing.getY() + BODY_FORMATION_HEIGHT;
   756→        double bodyZ = wangPing.getZ();
   757→
   758→        double midX = (crystalX + bodyX) / 2.0;
   759→        double midY = (crystalY + bodyY) / 2.0;
   760→        double midZ = (crystalZ + bodyZ) / 2.0;
   761→
   762→        // ── Descending END_ROD spiral at the Crystal (sword qi condensing) ──
   763→        // A spiral that descends from 4 blocks above the Crystal to chest height,
   764→        // representing sword qi condensing downward into the world.
   765→        for (int i = 0; i < CRYSTAL_SPIRAL_PARTICLE_COUNT; i++) {
   766→            double t = i / (double) CRYSTAL_SPIRAL_PARTICLE_COUNT;
   767→            double theta = t * Math.PI * 4;  // 2 full turns
   768→            double radius = 0.8 * (1.0 - t * 0.5);  // narrowing spiral
   769→            double dx = Math.cos(theta) * radius;
   770→            double dz = Math.sin(theta) * radius;
   771→            // Descending from 4 blocks above to chest height
   772→            double dy = 4.0 * (1.0 - t);
   773→            level.sendParticles(ParticleTypes.END_ROD,
   774→                    crystalX + dx, crystalPos.getY() + dy, crystalZ + dz, 1,
   775→                    0.0, -0.08, 0.0, 0.0);
   776→        }
   777→
   778→        // ── Body-formation END_ROD ring at Wang Ping (body coalescing) ──
   779→        // A ring at chest height, expanding outward — the body forming.
   780→        for (int i = 0; i < BODY_RING_PARTICLE_COUNT; i++) {
   781→            double theta = (i / (double) BODY_RING_PARTICLE_COUNT) * Math.PI * 2;
   782→            double radius = 0.6;
   783→            double dx = Math.cos(theta) * radius;
   784→            double dz = Math.sin(theta) * radius;
   785→            // Slight vertical jitter for a "body forming" effect
   786→            double dy = (i % 3 - 1) * 0.15;
   787→            level.sendParticles(ParticleTypes.END_ROD,
   788→                    bodyX + dx, bodyY + dy, bodyZ + dz, 1,
   789→                    0.0, 0.02, 0.0, 0.0);
   790→        }
   791→
   792→        // ── END_ROD stream from Crystal to Wang Ping (sword qi flowing) ──
   793→        for (int i = 0; i < SWORD_QI_STREAM_PARTICLE_COUNT; i++) {
   794→            double t = i / (double) (SWORD_QI_STREAM_PARTICLE_COUNT - 1);
   795→            double px = crystalX + (bodyX - crystalX) * t;
   796→            double py = crystalY + (bodyY - crystalY) * t;
   797→            double pz = crystalZ + (bodyZ - crystalZ) * t;
   798→            // Small lateral jitter for visual richness
   799→            double jitterX = (i % 3 - 1) * 0.08;
   800→            double jitterZ = (i % 5 - 2) * 0.08;
