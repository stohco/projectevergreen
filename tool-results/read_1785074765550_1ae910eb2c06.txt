    42→/**
    43→ * BlueprintChunkGenerator — a true algorithmically-independent chunk generator
    44→ * for Planet Suzaku whose surface terrain is derived from the
    45→ * {@link PlanetSuzakuBlueprint}'s canon geography (plus a tiny deterministic
    46→ * value-noise perturbation seeded by {@link DeterministicSeedHandler#CANON_SEED}),
    47→ * <em>not</em> from {@code minecraft:overworld} noise.
    48→ *
    49→ * <h2>CRON-COMPLETIONIST-60 — TRUE ALGORITHMIC INDEPENDENCE (point 10)</h2>
    50→ *
    51→ * <p>The CRON-71 design (this class's prior form) only wrapped
    52→ * {@link NoiseBasedChunkGenerator} and overrode {@link #getBaseHeight} to add
    53→ * canon terrain offsets on top of vanilla noise. The surface shape was still
    54→ * determined by {@code minecraft:overworld} noise — only nudged a few blocks
    55→ * per canon location. That was a "noise with offset" generator, not a "blueprint"
    56→ * generator. It failed the architectural goal of point 10: <i>"Terrain columns
    57→ * come from the blueprint+layers, not minecraft:overworld noise."</i>
    58→ *
    59→ * <p>This version (CRON-COMPLETIONIST-60) closes that gap:
    60→ * <ul>
    61→ *   <li>{@link #fillFromNoise} is overridden to fill each column from
    62→ *       {@link #canonSurfaceHeight(int, int)}, a pure deterministic function
    63→ *       of the blueprint's canon locations + {@link DeterministicSeedHandler#CANON_SEED}.</li>
    64→ *   <li>{@link #getBaseHeight} returns {@link #canonSurfaceHeight(int, int)}.</li>
    65→ *   <li>{@link #getBaseColumn} returns a column built from
    66→ *       {@link #canonSurfaceHeight(int, int)} — bedrock at the bottom, stone
    67→ *       up to the canon surface, water up to sea level, air above.</li>
    68→ * </ul>
    69→ *
    70→ * <p>The wrapped {@link NoiseBasedChunkGenerator} is still used for
    71→ * {@link #applyCarvers} (caves/ravines) and {@link #buildSurface} (grass/sand/
    72→ * snow/etc. biome surface rules). Those methods use vanilla's noise-derived
    73→ * carving and surface data, which is independent of the surface heightmap —
    74→ * they carve <i>through</i> whatever stone we placed, and apply surface rules
    75→ * on top of whatever stone surface we placed. This preserves caves, ores
    76→ * (ores are placed by feature decoration which queries existing stone), and
    77→ * biome surface variation for free.
    78→ *
    79→ * <p><b>Canon-driven surface formula:</b>
    80→ * <pre>{@code
    81→ *   canonSurfaceHeight(x, z) =
    82→ *       BASE_HEIGHT (64, one above sea level)
    83→ *     + sum_over_nearby_canon_locations(getTerrainWarpForLocation(loc)
    84→ *                                        * linearDecayFactor(distance, RADIUS=200))
    85→ *     + canonNoiseVariation(x, z)   // bilinear value noise, 8-block period,
    86→ *                                    // amplitude ±8, seeded by CANON_SEED
    87→ * }</pre>
    88→ *
    89→ * <h2>CRON-COMPLETIONIST-91 — BLUEPRINT+LAYERS INTEGRATION (point 10 full fidelity)</h2>
    90→ *
    91→ * <p>The CRON-60 design (this class's prior form) derived surface terrain from
    92→ * {@link PlanetSuzakuBlueprint} canon geography alone. That closed the
    93→ * "algorithmic independence from {@code minecraft:overworld} noise" gap, but
    94→ * left a deeper architectural promise unfulfilled: <i>"Terrain columns come
    95→ * from the blueprint+<b>layers</b>, not minecraft:overworld noise."</i>
    96→ *
    97→ * <p>The <b>layers</b> in that promise are the {@link CompositeWorldLayer}'s
    98→ * {@link WorldLayer}s — specifically the {@link Provenance#PLAYER} and
    99→ * {@link Provenance#SIMULATION} layers, which hold the journal of every
   100→ * block change since day 0. Before CRON-91, those layers were only consulted
   101→ * by {@link dev.ergenverse.runtime.materialize.PlanetSuzakuChunkMaterializer#onChunkLoad}
   102→ * — <b>deferred by 1 tick</b> to avoid mutating a chunk during its own assembly.
   103→ * The result: when a player walked back to a previously-edited area and the
   104→ * chunk regenerated from the canon base, there was a 1-tick window (50ms) where
   105→ * the player saw the unedited canon terrain <i>before</i> their PLAYER deltas
   106→ * were re-applied. A visible "flash of unedited terrain."
   107→ *
   108→ * <p>CRON-91 closes that gap. {@link #fillFromNoise} now does a <b>two-phase
   109→ * fill</b>:
   110→ * <ol>
   111→ *   <li><b>Phase 1 — canon base terrain.</b> Bedrock, stone up to
   112→ *       {@link #canonSurfaceHeight}, water up to {@link #SEA_LEVEL}, air above.
   113→ *       Unchanged from CRON-60.</li>
   114→ *   <li><b>Phase 2 — layer override.</b> If {@link WorldRuntime#get()} is
   115→ *       initialized, iterate {@link CompositeWorldLayer#layersInMaterializationOrder()}
   116→ *       and for each non-CANON layer, apply that layer's
   117→ *       {@link ChunkContribution#blockChanges} directly to the chunk via
   118→ *       {@link ChunkAccess#setBlockState}. This is safe during chunk-gen
   119→ *       (uses {@code isMoving=false}, no lighting/tick updates) and is
   120→ *       <b>idempotent</b> — {@code PlanetSuzakuChunkMaterializer.onChunkLoad}
   121→ *       will re-apply the same deltas 1 tick later as a safety net for the
   122→ *       chunk-from-disk reload path, where {@code fillFromNoise} does not fire.</li>
   123→ * </ol>
   124→ *
   125→ * <p><b>Why CANON structures are NOT built during {@code fillFromNoise}:</b>
   126→ * the {@link dev.ergenverse.runtime.materialize.StructureBuilderRegistry} builders
   127→ * need a live {@link net.minecraft.server.level.ServerLevel} (for entity spawns,
   128→ * heightmap resolution, etc.), but {@code fillFromNoise} only has a
   129→ * {@link ChunkAccess} (no level). CANON structure building stays in the
   130→ * materializer. PLAYER/SIMULATION block changes have no such dependency — they
   131→ * are pure (x, y, z, blockState) tuples — so they're safe to apply here.
   132→ *
   133→ * <p>The result: Heng Yue Mountain is always raised +30 near (4200, -1400),
   134→ * the Sea of Devils is always lowered −30 near (6000, -1184), Wang Family
   135→ * Village sits at +8 above sea level on a hill, etc. — every playthrough,
   136→ * regardless of vanilla noise seed. The hand-placed spawn at (3842, -1184)
   137→ * always lands on the same hill. This is <i>true algorithmic independence</i>
   138→ * from {@code minecraft:overworld} noise.
   139→ *
   140→ * <p><b>Codec &amp; registration:</b> Registered as {@code ergenverse:blueprint}
   141→ * via {@link ErgenverseChunkGenerators#BLUEPRINT}. The dimension JSON at
   142→ * {@code data/ergenverse/dimension/planet_suzaku.json} references the generator
   143→ * type as {@code ergenverse:blueprint} with {@code settings: minecraft:overworld}
   144→ * (the overworld settings are used for cave/surface-rule configuration, NOT for
   145→ * surface terrain shape — that comes from this generator).
   146→ *
   147→ * <p><b>Canon fidelity (fact-checked against 仙逆):</b>
   148→ * <ul>
   149→ *   <li>恒岳山 (Heng Yue Mountain): Zhao Country's largest mountain, raised +30.</li>
   150→ *   <li>修魔海 (Sea of Devils): vast perilous sea east of Zhao, lowered −30 → ocean.</li>
   151→ *   <li>朱雀墓 (Suzaku Tomb): underground inheritance site, surface depressed −12.</li>
   152→ *   <li>Wang Family Village: "赵国某偏僻小山村" — remote mountain village, raised +8.</li>
   153→ *   <li>藤家城 (Teng Family City): powerful family city in Zhao, raised +10.</li>
   154→ *   <li>雪域国 (Snow Domain): cold elevated country, raised +10.</li>
   155→ *   <li>恒岳派 / 炼魂宗 / 玄道宗 / 洛河门: mountain sects, raised +12 to +15.</li>
   156→ * </ul>
   157→ *
   158→ * <p><b>Known trade-offs (hyper-analytical self-critique):</b>
   159→ * <ul>
   160→ *   <li>The base noise variation is bilinear value noise (8-block period,
   161→ *       ±8 amplitude). This is intentionally crude — its purpose is to break
   162→ *       the perfectly-flat plateau that pure canon warping would produce
   163→ *       between canon locations, NOT to mimic natural terrain. Real terrain
   164→ *       variety now comes from biome-aware profiles (CRON-93) AND biome
   165→ *       surface rules (grass/sand/snow) applied by {@link #buildSurface}.</li>
   166→ *   <li>Caves are carved by vanilla carvers, which use vanilla noise to
   167→ *       determine WHERE to carve. Because our surface is canon-shaped (not
   168→ *       vanilla-noise-shaped), caves may occasionally carve into air (above
   169→ *       our surface where vanilla expected stone) or fail to carve (below our
   170→ *       surface where vanilla expected air). The net effect: caves still
   171→ *       exist but their density/surface-entrance distribution may differ
   172→ *       from a vanilla world. This is acceptable — the canon world has caves,
   173→ *       they just don't align with vanilla noise.</li>
   174→ *   <li>Ores are placed by feature decoration, which queries existing stone
   175→ *       blocks. Since we fill stone up to the canon surface, ores will be
   176→ *       placed normally. No loss here.</li>
   177→ *   <li>Aquifers (underground water) are part of vanilla noise generation.
   178→ *       Skipping vanilla {@code fillFromNoise} means we lose aquifers. This
   179→ *       is a known limitation; aquifers are mostly invisible to the player
   180→ *       (underground water pools) and the Sea of Devils already provides
   181→ *       surface water via our canon fill.</li>
   182→ *   <li>The wrapped generator's {@link NoiseBasedChunkGenerator#fillFromNoise}
   183→ *       is NOT called, so {@code chunk.getOrCreateNoiseChunk(...)} will be
   184→ *       lazily computed on first access (by {@code applyCarvers} or
   185→ *       {@code buildSurface}). This is fine — vanilla supports lazy
   186→ *       NoiseChunk computation.</li>
   187→ * </ul>
   188→ *
   189→ * <h2>CRON-COMPLETIONIST-93 — BIOME-AWARE TERRAIN PROFILES</h2>
   190→ *
   191→ * <p>The CRON-60/91 design derived surface height from canon geography +
   192→ * a flat ±8 fine noise, ignoring the biome entirely. A column in a
   193→ * {@code zhao_mountains} biome got the SAME surface height (Y=64 ± noise)
   194→ * as a column in a {@code zhao_plains} biome. This was a major visual
   195→ * regression from vanilla {@code minecraft:noise}, where mountains rise
   196→ * to Y=120+ and plains stay at Y=64. The world looked like a flat plateau
   197→ * with occasional canon-warped bumps — not a real cultivation world with
   198→ * mountains, plains, oceans, and valleys.
   199→ *
   200→ * <p>CRON-93 closes this gap by adding a {@link BiomeTerrainProfile}
   201→ * lookup to the height computation. The new
   202→ * {@link #biomeAwareSurfaceHeight(int, int, RandomState)} samples the biome
   203→ * source at (x, z) via {@link BiomeSource#getNoiseBiome}, looks up the
   204→ * profile for that biome, and uses the profile's base height + amplitude
   205→ * as the primary determinant of surface shape. Canon warps and fine noise
   206→ * still apply on top.
   207→ *
   208→ * <p><b>New formula (CRON-93):</b>
   209→ * <pre>{@code
   210→ *   biomeAwareSurfaceHeight(x, z) =
   211→ *       biomeProfile.baseHeight                  // plains=64, mountains=110, ocean=35
   212→ *     + biomeAmplitudeNoise(x, z, amplitude)     // ±amplitude, period 24
   213→ *     + canonTerrainOffset(x, z)                 // ±30 from canon locations
   214→ *     + canonNoiseVariation(x, z)                // ±8 fine noise (period 8)
   215→ *     clamped to [2, 256]
   216→ * }</pre>
   217→ *
   218→ * <p>The legacy static {@link #canonSurfaceHeight(int, int)} is RETAINED
   219→ * as a fallback for contexts where no {@link RandomState} is available
   220→ * (e.g., early chunk-gen race, non-Suzaku levels). It returns the
   221→ * pre-CRON-93 height (base 64 + canon warp + fine noise). Structure
   222→ * builders that have a {@link net.minecraft.server.level.ServerLevel}
   223→ * should call the new {@link #surfaceHeightFor(ServerLevel, int, int)}
   224→ * instead, which delegates to the biome-aware instance method.
   225→ *
   226→ * <h2>CRON-COMPLETIONIST-104 — CANON-AWARE CAVE PLACEMENT</h2>
   227→ *
   228→ * <p>The CRON-60/91/93 design derived surface terrain from canon geography
   229→ * + biome profiles, but left {@link #applyCarvers} as a thin delegate to
   230→ * the wrapped {@link NoiseBasedChunkGenerator}. Vanilla carvers use vanilla
   231→ * noise to decide where to carve caves — they have no awareness of canon
   232→ * geography. The result: vanilla caves could carve through the Suzaku Tomb
   233→ * (朱雀墓 — the sacred underground inheritance site of the 朱雀子 lineage),
   234→ * under Wang Family Village (王家村 — Wang Lin's birthplace), under Heng
   235→ * Yue Sect (恒岳派 — Wang Lin's first sect), and under every other
   236→ * settlement/sect/ruin. This was a <b>canon-fidelity violation</b>: those
   237→ * sites are canonically sealed, constructed, or sacred — caves undermine
   238→ * their foundations and break immersion.
   239→ *
   240→ * <p>CRON-104 closes this gap by overriding {@link #applyCarvers} with the
   241→ * {@link #shouldSuppressCarvers} guard. When the chunk's (x, z) bounding
   242→ * box intersects any protected canon location's suppression circle, the
   243→ * carver call is skipped entirely — no caves, no ravines, no canyons.
   244→ * Protected categories: {@code settlement} (7 locations), {@code sect}
   245→ * (4 locations), {@code ruin} (1 location: Suzaku Tomb with extended
   246→ * radius). Unprotected: {@code region}, {@code geographic},
   247→ * {@code dangerous_region} (caves remain active — they are part of the
   248→ * canon geography in those areas).
   249→ *
   250→ * <p>Suppression radii: 80 blocks default (covers a 5-chunk radius around
   251→ * the structure center), 150 blocks for the Suzaku Tomb (the largest,
   252→ * most sacred underground site). The check is a fast rectangle-circle
   253→ * intersection test — O(num_protected_locations) per chunk, currently
   254→ * 12 distance checks per chunk. Negligible cost.
   255→ *
   256→ * <p>The {@link #addDebugScreenInfo} now reports the cave-suppression
   257→ * status at the player's position ("Cave suppression: ACTIVE near
   258→ * Heng Yue Sect (r=80)" or "Cave suppression: inactive"), so the player
   259→ * can verify the canon-fidelity guard is working.
   260→ *
   261→ * <p>MC 1.20.1 / Forge 47.4.0 / Java 17.</p>
   262→ */

   398→    private BlueprintChunkGenerator(BiomeSource biomeSource,
   399→                                     Holder<NoiseGeneratorSettings> noiseSettings) {
   400→        super(biomeSource);
   401→        this.noiseSettings = noiseSettings;
   402→        this.wrapped = new NoiseBasedChunkGenerator(biomeSource, noiseSettings);

   405→    // ════════════════════════════════════════════════════════════════════
   406→    //  CHUNK GENERATION — TRUE ALGORITHMIC INDEPENDENCE

   408→
   409→    @Override
   410→    protected Codec<? extends ChunkGenerator> codec() {
   411→        return CODEC;
   412→    }
   413→
   414→    /**
   415→     * Fill the chunk with canon-derived terrain.
   416→     *
   417→     * <p>This is the heart of the algorithmic independence: surface height
   418→     * per column comes from {@link #canonSurfaceHeight(int, int)}, NOT from
   419→     * vanilla noise. The wrapped {@link NoiseBasedChunkGenerator#fillFromNoise}
   420→     * is NOT called — we generate terrain entirely from canon geography.
   421→     *
   422→     * <p>Vanilla {@link #applyCarvers} and {@link #buildSurface} will lazily
   423→     * compute the {@code NoiseChunk} they need for cave placement and surface
   424→     * rules; those operations do NOT depend on the surface heightmap that
   425→     * {@code fillFromNoise} would have produced.
   426→     */
   427→    @Override
   428→    public CompletableFuture<ChunkAccess> fillFromNoise(Executor executor, Blender blender,
   429→                                                           RandomState randomState,
   430→                                                           StructureManager structureManager,
   431→                                                           ChunkAccess chunk) {
   432→        int minY = chunk.getMinBuildHeight();
   433→        int maxY = chunk.getMaxBuildHeight();
   434→        int minChunkX = chunk.getPos().getMinBlockX();
   435→        int minChunkZ = chunk.getPos().getMinBlockZ();
   436→
   437→        // ── Phase 1: canon base terrain (bedrock / stone / water / air) ──
   438→        // Cache block states — BlockState lookup is cheap but de-virtualized
   439→        // local refs are still marginally faster in a hot loop.
   440→        final BlockState stone = Blocks.STONE.defaultBlockState();
   441→        final BlockState water = Blocks.WATER.defaultBlockState();
   442→        final BlockState bedrock = Blocks.BEDROCK.defaultBlockState();
   443→
   444→        // MutableBlockPos avoids per-block allocation. setBlockState on a
   445→        // ProtoChunk during chunk-gen does NOT trigger lighting/scheduled
   446→        // tick updates — it just writes the section state.
   447→        BlockPos.MutableBlockPos pos = new BlockPos.MutableBlockPos();
   448→
   449→        for (int localX = 0; localX < 16; localX++) {
   450→            for (int localZ = 0; localZ < 16; localZ++) {
   451→                int worldX = minChunkX + localX;
   452→                int worldZ = minChunkZ + localZ;
   453→                // CRON-93: biome-aware height (mountains=110, plains=64,
   454→                // ocean=35, etc.) — replaces the flat canonSurfaceHeight.
   455→                // Falls back to legacy static if randomState is null.
   456→                int surfaceHeight = biomeAwareSurfaceHeight(worldX, worldZ, randomState);
   457→
   458→                for (int y = minY; y < maxY; y++) {
   459→                    BlockState state;
   460→                    if (y == minY) {
   461→                        state = bedrock;
   462→                    } else if (y < surfaceHeight) {
   463→                        state = stone;
   464→                    } else if (y < SEA_LEVEL) {
   465→                        state = water;
   466→                    } else {
   467→                        // Air — leave the section's default (air). Skip
   468→                        // setBlockState to avoid 65K useless writes per
   469→                        // column above the surface.
   470→                        continue;
   471→                    }
   472→
   473→                    pos.set(worldX, y, worldZ);
   474→                    chunk.setBlockState(pos, state, false);
   475→                }
   476→            }
   477→        }
   478→
   479→        // ── Phase 2: apply PLAYER + SIMULATION layer overrides (CRON-91) ──
   480→        // The architectural promise in point 10 is "terrain columns come from
   481→        // the blueprint+LAYERS" — not just the blueprint. Before CRON-91, the
   482→        // PLAYER/SIMULATION layers were only consulted by the chunk materializer
   483→        // on ChunkEvent.Load (deferred 1 tick), causing a visible flash of
   484→        // unedited canon terrain when a player walked back to a previously-edited
   485→        // area. Applying the layer overrides directly during fillFromNoise closes
   486→        // that 1-tick window: the player sees their edits immediately when the
   487→        // chunk first becomes visible.
   488→        //
   489→        // Safety:
   490→        //   - chunk.setBlockState(pos, state, false) is the SAME write path
   491→        //     vanilla's NoiseBasedChunkGenerator.fillFromNoise uses; it writes
   492→        //     the section state without triggering lighting/tick updates.
   493→        //   - This is NOT the same as level.setBlock(pos, state, UPDATE_ALL),
   494→        //     which is what the materializer defers to avoid. We are writing
   495→        //     to the ProtoChunk during its own assembly — exactly what
   496→        //     fillFromNoise is designed to do.
   497→        //   - Idempotent with the materializer: setting the same block to the
   498→        //     same state is a no-op. The materializer is still needed for the
   499→        //     chunk-from-disk reload path (where fillFromNoise does NOT fire).
   500→        //   - CANON structures (c.structures) are intentionally NOT built here
   501→        //     — StructureBuilderRegistry builders need a live ServerLevel, but
   502→        //     fillFromNoise only has a ChunkAccess. CANON stays in the materializer.
   503→        applyLayerOverrides(chunk, pos);
   504→
   505→        // Synchronous fill — return already-completed future. Vanilla's
   506→        // NoiseBasedChunkGenerator runs fillFromNoise on a worker thread via
   507→        // supplyAsync(executor); we don't need to because our fill is
   508→        // CPU-bound and fast (no noise sampling, no aquifer computation).
   509→        return CompletableFuture.completedFuture(chunk);
   510→    }

   512→    /**
   513→     * Apply PLAYER and SIMULATION layer overrides to a chunk during fillFromNoise.
   514→     *
   515→     * <p>For each non-CANON layer in {@link CompositeWorldLayer#layersInMaterializationOrder()},
   516→     * queries {@link WorldLayer#getChunkContribution(int, int)} and applies any
   517→     * {@link BlockChangeDelta}s directly to the chunk via
   518→     * {@link ChunkAccess#setBlockState}. This is the CRON-91 upgrade that makes
   519→     * "terrain columns come from the blueprint+LAYERS" literally true — the
   520→     * layer journal is consulted during chunk-gen, not deferred to ChunkEvent.Load.
   521→     *
   522→     * <p><b>No-op when:</b>
   523→     * <ul>
   524→     *   <li>{@link WorldRuntime#get()} is not yet initialized (race during
   525→     *       server start — the runtime binds to the level on ServerStartingEvent,
   526→     *       which may fire AFTER the initial spawn chunks generate). In this
   527→     *       case, the materializer's onChunkLoad will apply the deltas 1 tick
   528→     *       later as a fallback.</li>
   529→     *   <li>The chunk has no PLAYER or SIMULATION deltas (the common case —
   530→     *       most chunks are unedited). The contribution is empty and the loop
   531→     *       is a near-noop.</li>
   532→     * </ul>
   533→     *
   534→     * @param chunk the chunk being assembled (Phase 1 base terrain already placed)
   535→     * @param pos   a reusable MutableBlockPos (avoids per-delta allocation)
   536→     */
   537→    private void applyLayerOverrides(ChunkAccess chunk, BlockPos.MutableBlockPos pos) {
   538→        // Defensive: WorldRuntime may not be initialized yet during the very
   539→        // first chunk-gen pass at server start. The materializer will catch up.
   540→        WorldRuntime runtime;
   541→        try {
   542→            runtime = WorldRuntime.get();
   543→            if (!runtime.isInitialized()) return;
   544→        } catch (Throwable t) {
   545→            Ergenverse.LOGGER.debug("[Ergenverse] BlueprintChunkGenerator: WorldRuntime unavailable during fillFromNoise — deferring layer overrides to materializer. Reason: {}",
   546→                    t.getMessage());
   547→            return;
   548→        }
   549→
   550→        CompositeWorldLayer worldLayer = runtime.worldLayer();
   551→        if (worldLayer == null) return;
   552→
   553→        int chunkX = chunk.getPos().x;
   554→        int chunkZ = chunk.getPos().z;
   555→
   556→        // Iterate in materialization order: CANON first → SIMULATION → PLAYER.
   557→        // PLAYER wins on conflict (applied last). CANON layer's c.structures
   558→        // are skipped (need a live ServerLevel — materializer handles those).
   559→        for (WorldLayer layer : worldLayer.layersInMaterializationOrder()) {
   560→            if (layer.provenance() == Provenance.CANON) continue;
   561→
   562→            ChunkContribution contribution;
   563→            try {
   564→                contribution = layer.getChunkContribution(chunkX, chunkZ);
   565→            } catch (Throwable t) {
   566→                Ergenverse.LOGGER.debug("[Ergenverse] BlueprintChunkGenerator: layer {} getChunkContribution failed for chunk ({},{}): {}",
   567→                        layer.provenance(), chunkX, chunkZ, t.getMessage());
   568→                continue;
   569→            }
   570→            if (contribution == null || contribution.isEmpty()) continue;
   571→
   572→            for (BlockChangeDelta delta : contribution.blockChanges) {
   573→                BlockState state = resolveBlockState(delta.blockState());
   574→                if (state == null) continue;
   575→                pos.set(delta.x(), delta.y(), delta.z());
   576→                chunk.setBlockState(pos, state, false);
   577→            }
   578→        }
   579→    }

   583→     *
   584→     * <p><b>CRON-COMPLETIONIST-94:</b> now delegates to
   585→     * {@link dev.ergenverse.runtime.delta.BlockStateCodec#parse} which
   586→     * supports property overrides (e.g. {@code "minecraft:chest[facing=north]"}).

   716→    /**
   717→     * Determine whether cave carvers should be suppressed for the given
   718→     * chunk. Returns true iff the chunk's (x, z) bounding box intersects
   719→     * any protected canon location's suppression circle.
   720→     *
   721→     * <p>The check is a fast rectangle-circle intersection test: for each
   722→     * protected location, find the closest point on the chunk's bounding
   723→     * box to the location's center, then check if the squared distance is
   724→     * within the squared radius. This is O(num_protected_locations) per
   725→     * chunk — currently 12 protected locations, so 12 distance checks per
   726→     * chunk. Negligible cost.
   727→     *
   728→     * <p><b>No Y-axis filter:</b> the suppression is per-column, not
   729→     * per-block. The Suzaku Tomb at y=-60 protects ALL carve steps in the
   730→     * chunk column above and around it — the entire (x, z) footprint is
   731→     * sealed. This is correct because vanilla carvers operate per-chunk
   732→     * with a Y range, and we want to seal the entire column to prevent
   733→     * any cave from breaching the sacred chamber.
   734→     *
   735→     * @param chunk the chunk about to be carved
   736→     * @return true iff carvers should be skipped for this chunk
   737→     */
   738→    private boolean shouldSuppressCarvers(ChunkAccess chunk) {
   739→        int chunkMinX = chunk.getPos().getMinBlockX();
   740→        int chunkMaxX = chunk.getPos().getMaxBlockX();
   741→        int chunkMinZ = chunk.getPos().getMinBlockZ();
   742→        int chunkMaxZ = chunk.getPos().getMaxBlockZ();
   743→
   744→        PlanetSuzakuBlueprint blueprint = PlanetSuzakuBlueprint.canonical();
   745→        for (PlanetSuzakuBlueprint.CanonLocation loc : blueprint.allLocations().values()) {
   746→            if (!isProtectedCategory(loc.category)) continue;
   747→            int radius = getCaveSuppressionRadius(loc);
   748→            // Closest point on the chunk's (x, z) bounding box to the
   749→            // location's center, then check squared distance.
   750→            int closestX = Math.max(chunkMinX, Math.min(loc.x, chunkMaxX));
   751→            int closestZ = Math.max(chunkMinZ, Math.min(loc.z, chunkMaxZ));
   752→            int dx = loc.x - closestX;
   753→            int dz = loc.z - closestZ;
   754→            if (dx * dx + dz * dz <= radius * radius) {
   755→                return true;
   756→            }
   757→        }
   758→        return false;
   759→    }

   862→    /**
   863→     * Get the base noise column at (x, z), built from biome-aware surface height.
   864→     * Returns bedrock at the bottom, stone up to the surface, water
   865→     * up to sea level, air above.
   866→     */
   867→    @Override
   868→    public NoiseColumn getBaseColumn(int x, int z, LevelHeightAccessor level,
   869→                                      RandomState randomState) {
   870→        int minY = level.getMinBuildHeight();
   871→        int height = level.getHeight();
   872→        int surfaceHeight = biomeAwareSurfaceHeight(x, z, randomState);
   873→
   874→        BlockState[] states = new BlockState[height];
   875→        for (int i = 0; i < height; i++) {
   876→            int y = minY + i;
   877→            if (y == minY) {
   878→                states[i] = Blocks.BEDROCK.defaultBlockState();
   879→            } else if (y < surfaceHeight) {
   880→                states[i] = Blocks.STONE.defaultBlockState();
   881→            } else if (y < SEA_LEVEL) {
   882→                states[i] = Blocks.WATER.defaultBlockState();
   883→            } else {
   884→                states[i] = Blocks.AIR.defaultBlockState();
   885→            }
   886→        }
   887→        return new NoiseColumn(minY, states);
   888→    }

   936→    /**
   937→     * Compute the biome-aware surface height at (worldX, worldZ), the
   938→     * authoritative height function used by {@link #fillFromNoise},
   939→     * {@link #getBaseHeight}, {@link #getBaseColumn}, and (via
   940→     * {@link #surfaceHeightFor}) structure builders.
   941→     *
   942→     * <p>Formula (CRON-93):
   943→     * <pre>{@code
   944→     *   biomeProfile.baseHeight                  // plains=64, mountains=110, ocean=35
   945→     *     + biomeAmplitudeNoise(x, z, amplitude) // ±amplitude, period 24
   946→     *     + canonTerrainOffset(x, z)             // ±30 from canon locations
   947→     *     + canonNoiseVariation(x, z)            // ±8 fine noise (period 8)
   948→     *     clamped to [2, 256]
   949→     * }</pre>
   950→     *
   951→     * <p>The biome is sampled at (worldX, worldZ) via
   952→     * {@link BiomeSource#getNoiseBiome} using the {@link RandomState}'s
   953→     * {@link RandomState#sampler() climate sampler}. The quart Y is
   954→     * {@link #BIOME_SAMPLE_QUART_Y} (sea level), ensuring we get the surface
   955→     * biome, not a cave or high-altitude variant.
   956→     *
   957→     * <p><b>Fallback behavior:</b> if {@code randomState} is {@code null}, or
   958→     * the biome lookup fails for any reason, this method falls back to the
   959→     * legacy {@link #canonSurfaceHeight(int, int)} (no biome awareness).
   960→     * This ensures robustness during edge cases (early chunk-gen race,
   961→     * non-Suzaku levels) at the cost of biome-blind height.
   962→     *
   963→     * @param worldX      the world X coordinate
   964→     * @param worldZ      the world Z coordinate
   965→     * @param randomState the world's random state (provides the climate sampler);
   966→     *                    may be {@code null} for fallback behavior
   967→     * @return the biome-aware surface height, clamped to [2, 256]
   968→     */
   969→    public int biomeAwareSurfaceHeight(int worldX, int worldZ, RandomState randomState) {
   970→        // Fallback: no randomState → use legacy static (no biome awareness)
   971→        if (randomState == null) {
   972→            return canonSurfaceHeight(worldX, worldZ);
   973→        }
   974→
   975→        BiomeTerrainProfile profile = sampleBiomeProfile(worldX, worldZ, randomState);
   976→        int offset = getCanonTerrainOffset(worldX, worldZ);
   977→        int fineNoise = canonNoiseVariation(worldX, worldZ);
   978→        int biomeNoise = biomeAmplitudeNoise(worldX, worldZ, profile.amplitude());
   979→
   980→        int h = profile.baseHeight() + biomeNoise + offset + fineNoise;
   981→        // Clamp: same [2, 256] bounds as canonSurfaceHeight
   982→        if (h < 2) return 2;
   983→        if (h > 256) return 256;
   984→        return h;
   985→    }

   987→    /**
   988→     * Sample the biome at (worldX, worldZ) and return its terrain profile.
   989→     *
   990→     * <p>Uses {@link BiomeSource#getNoiseBiome} with the climate sampler from
   991→     * {@code randomState}. The quart Y is {@link #BIOME_SAMPLE_QUART_Y}
   992→     * (sea level). Returns {@link BiomeTerrainProfile#DEFAULT} if the lookup
   993→     * fails for any reason (defensive — should not occur in practice).
   994→     */
   995→    private BiomeTerrainProfile sampleBiomeProfile(int worldX, int worldZ, RandomState randomState) {
   996→        try {
   997→            int quartX = worldX >> 2;
   998→            int quartZ = worldZ >> 2;
   999→            // In 1.20.1 Mojmaps, RandomState.sampler() returns the Climate.Sampler
  1000→            // used by the multi-noise biome source. Quart resolution is 4 blocks;
  1001→            // quartY = 16 corresponds to world Y = 64 (sea level) — see BIOME_SAMPLE_QUART_Y.
  1002→            Climate.Sampler sampler = randomState.sampler();
  1003→            Holder<Biome> biome = biomeSource.getNoiseBiome(quartX, BIOME_SAMPLE_QUART_Y, quartZ, sampler);
  1004→            if (biome == null) return BiomeTerrainProfile.DEFAULT;
  1005→            return biome.unwrapKey()
  1006→                    .map(key -> BiomeTerrainProfile.forBiome(key.location()))
  1007→                    .orElse(BiomeTerrainProfile.DEFAULT);
  1008→        } catch (Throwable t) {
  1009→            Ergenverse.LOGGER.debug("[Ergenverse] BlueprintChunkGenerator: biome sample failed at ({},{}): {}",
  1010→                    worldX, worldZ, t.getMessage());
  1011→            return BiomeTerrainProfile.DEFAULT;
  1012→        }
  1013→    }

  1015→    /**
  1016→     * Get the biome-aware surface height at (worldX, worldZ) for the given
  1017→     * {@link ServerLevel}. This is the entry point structure builders
  1018→     * should use (CRON-93).
  1019→     *
  1020→     * <p>If the level's chunk generator is a {@link BlueprintChunkGenerator},
  1021→     * this delegates to {@link #biomeAwareSurfaceHeight} with the level's
  1022→     * {@link RandomState}. Otherwise (e.g., non-Suzaku levels, fallback
  1023→     * generators), it falls back to the legacy {@link #canonSurfaceHeight}
  1024→     * (no biome awareness).
  1025→     *
  1026→     * <p><b>Migration guide (CRON-93):</b> structure builders should replace
  1027→     * calls to the static {@code canonSurfaceHeight(x, z)} with
  1028→     * {@code surfaceHeightFor(level, x, z)}. Both return the same value when
  1029→     * the level is Suzaku, but the new method accounts for the biome at
  1030→     * (x, z), producing canon-faithful elevations (mountains at Y=110,
  1031→     * plains at Y=64, oceans at Y=35, etc.).
  1032→     *
  1033→     * <pre>{@code
  1034→     *   // BEFORE (CRON-67, no biome awareness):
  1035→     *   int surfaceY = BlueprintChunkGenerator.canonSurfaceHeight(SECT_X, SECT_Z);
  1036→     *
  1037→     *   // AFTER (CRON-93, biome-aware):
  1038→     *   int surfaceY = BlueprintChunkGenerator.surfaceHeightFor(level, SECT_X, SECT_Z);
  1039→     * }</pre>
  1040→     *
  1041→     * @param level  the server level (must be Planet Suzaku for biome-aware
  1042→     *               results; other levels fall back to legacy behavior)
  1043→     * @param worldX the world X coordinate
  1044→     * @param worldZ the world Z coordinate
  1045→     * @return the biome-aware surface height for Suzaku levels; legacy
  1046→     *         canonSurfaceHeight for other levels

  1050→            ChunkGenerator gen = level.getChunkSource().getGenerator();

  1052→                RandomState randomState = level.getChunkSource().randomState();

  1058→                    "Falling back to legacy canonSurfaceHeight.",
  1059→                    worldX, worldZ, level.dimension(), t.getMessage());

  1068→    /**
  1069→     * Compute the canon-derived surface height at (worldX, worldZ) — the
  1070→     * <b>legacy, biome-blind</b> version.
  1071→     *
  1072→     * <p>{@code BASE_SURFACE_HEIGHT + canonTerrainOffset + canonNoiseVariation},
  1073→     * clamped to a non-negative minimum (bedrock layer at {@code minY} must
  1074→     * always have at least one stone block above it).
  1075→     *
  1076→     * <p><b>CRON-COMPLETIONIST-93:</b> this method is RETAINED as a fallback
  1077→     * for contexts where no {@link RandomState} or {@link ServerLevel} is
  1078→     * available (e.g., early chunk-gen race, non-Suzaku levels, defensive
  1079→     * code paths). For all structure-builder contexts where a
  1080→     * {@link ServerLevel} is available, prefer
  1081→     * {@link #surfaceHeightFor(ServerLevel, int, int)} — it accounts for
  1082→     * the biome at (x, z) and produces canon-faithful elevations.
  1083→     *
  1084→     * <p><b>CRON-COMPLETIONIST-67:</b> this method is {@code public} so that
  1085→     * structure builders can resolve their center Y from the <i>same canon
  1086→     * authority</i> that the chunk generator uses — eliminating the heightmap
  1087→     * race condition where {@code level.getHeightmapPos(MOTION_BLOCKING_NO_LEAVES, ...)}
  1088→     * would return y=0 or a stale value if the chunk at the canon center wasn't
  1089→     * loaded yet when {@code buildForChunk} fired for an adjacent chunk. The
  1090→     * canon surface height is a pure deterministic function of (x, z) — it does
  1091→     * NOT depend on chunk-load state, so it returns the correct Y every time,
  1092→     * regardless of which chunks are loaded.
  1093→     *
  1094→     * <p>For contexts without a {@link ServerLevel} (e.g., static helpers,
  1095→     * tests), continue to call this directly:
  1096→     * <pre>{@code
  1097→     *   int surfaceY = BlueprintChunkGenerator.canonSurfaceHeight(SECT_X, SECT_Z);
  1098→     * }</pre>
  1099→     *
  1100→     * For contexts WITH a {@link ServerLevel}, prefer the biome-aware version:
  1101→     * <pre>{@code
  1102→     *   int surfaceY = BlueprintChunkGenerator.surfaceHeightFor(level, SECT_X, SECT_Z);
  1103→     * }</pre>
  1104→     */
  1105→    public static int canonSurfaceHeight(int worldX, int worldZ) {
  1106→        int offset = getCanonTerrainOffset(worldX, worldZ);
  1107→        int noise = canonNoiseVariation(worldX, worldZ);
  1108→        int h = BASE_SURFACE_HEIGHT + offset + noise;
  1109→        // Clamp: never let the surface drop to or below 1 (need at least
  1110→        // bedrock + stone). Also never exceed a sane cap to avoid Y=320
  1111→        // pillars on canon warps (current max warp is +30, so the cap is
  1112→        // mostly a defensive measure).
  1113→        if (h < 2) return 2;
  1114→        if (h > 256) return 256;
  1115→        return h;
  1116→    }

  1118→    /**
  1119→     * Compute the biome-amplitude noise at (worldX, worldZ) — a bilinear
  1120→     * value noise with period {@link #BIOME_NOISE_PERIOD} and the given
  1121→     * amplitude. Used by {@link #biomeAwareSurfaceHeight} to produce
  1122→     * biome-scale terrain variation (mountain peaks, valley undulations).
  1123→     *
  1124→     * <p>Returns 0 when {@code amplitude <= 0} (no variation needed for
  1125→     * flat biomes like plains, though plains still use amplitude 4 for
  1126→     * gentle rolling).
  1127→     *
  1128→     * <p>The hash function is the same splitmix64 mixer used by
  1129→     * {@link #canonNoiseVariation}, but with a different cell period (24
  1130→     * vs 8), so the two noise layers are decorrelated. Both are seeded by
  1131→     * {@link DeterministicSeedHandler#CANON_SEED}, ensuring determinism.
  1132→     */
  1133→    static int biomeAmplitudeNoise(int worldX, int worldZ, int amplitude) {
  1134→        if (amplitude <= 0) return 0;
  1135→        int cellX = Math.floorDiv(worldX, BIOME_NOISE_PERIOD);
  1136→        int cellZ = Math.floorDiv(worldZ, BIOME_NOISE_PERIOD);
  1137→        int fracX = worldX - cellX * BIOME_NOISE_PERIOD;
  1138→        int fracZ = worldZ - cellZ * BIOME_NOISE_PERIOD;
  1139→
  1140→        // Smoothstep interpolation weights
  1141→        double sx = (double) fracX / BIOME_NOISE_PERIOD;
  1142→        double sz = (double) fracZ / BIOME_NOISE_PERIOD;
  1143→        sx = sx * sx * (3 - 2 * sx);
  1144→        sz = sz * sz * (3 - 2 * sz);
  1145→
  1146→        // Four corner values in range [0, 2*amplitude]
  1147→        double v00 = amplitudeHash(cellX,     cellZ,     amplitude);
  1148→        double v10 = amplitudeHash(cellX + 1, cellZ,     amplitude);
  1149→        double v01 = amplitudeHash(cellX,     cellZ + 1, amplitude);
  1150→        double v11 = amplitudeHash(cellX + 1, cellZ + 1, amplitude);
  1151→
  1152→        double ix0 = v00 + (v10 - v00) * sx;
  1153→        double ix1 = v01 + (v11 - v01) * sx;
  1154→        double val = ix0 + (ix1 - ix0) * sz;
  1155→
  1156→        // Center around zero: range [-amplitude, +amplitude]
  1157→        return (int) Math.round(val - amplitude);
  1158→    }
  1159→
  1160→    /**
  1161→     * Salt value mixed into the amplitude-noise hash to decorrelate it from
  1162→     * the fine-noise hash (so the two noise layers don't produce correlated
  1163→     * values). Arbitrary 64-bit constant; chosen to be distinct from any
  1164→     * multiplier used in {@link #noiseHash}.
  1165→     */
  1166→    private static final long AMPLITUDE_HASH_SALT = 0xA5A5A5A5A5A5A5A5L;
  1167→
  1168→    /**
  1169→     * Deterministic hash for the biome-amplitude noise → value in
  1170→     * [0, 2 * amplitude]. Same splitmix64 mixing as {@link #noiseHash} but
  1171→     * parameterized by amplitude (so different amplitudes produce different
  1172→     * value ranges). Uses {@link #AMPLITUDE_HASH_SALT} to decorrelate from
  1173→     * the fine noise (otherwise the two noise layers would be correlated,
  1174→     * producing unrealistic terrain).
  1175→     */
  1176→    private static long amplitudeHash(int cellX, int cellZ, int amplitude) {
  1177→        long h = DeterministicSeedHandler.CANON_SEED ^ AMPLITUDE_HASH_SALT;
  1178→        h ^= (long) cellX * 0x9E3779B97F4A7C15L;
  1179→        h ^= (long) cellZ * 0xC2B2AE3D27D4EB4FL;
  1180→        h ^= h >>> 33;
  1181→        h *= 0xFF51AFD7ED558CCDL;
  1182→        h ^= h >>> 33;
  1183→        h *= 0xC4CEB9FE1A85EC53L;
  1184→        h ^= h >>> 33;
  1185→        return (h & 0xFFFFFFFFL) % (2L * amplitude + 1);
  1186→    }

  1188→    /**
  1189→     * Compute the canon terrain offset at (worldX, worldZ).
  1190→     * Returns the sum of all nearby canon location influences.
  1191→     * Positive = raise terrain (mountain), Negative = lower terrain (sea/tomb).
  1192→     *
  1193→     * <p>Each canon location has an influence that decays linearly from its
  1194→     * center to {@link #TERRAIN_WARP_RADIUS} blocks away. The offset is
  1195→     * deterministic and based on the blueprint's geography.
  1196→     */
  1197→    static int getCanonTerrainOffset(int worldX, int worldZ) {
  1198→        PlanetSuzakuBlueprint blueprint = PlanetSuzakuBlueprint.canonical();
  1199→        int totalOffset = 0;
  1200→
  1201→        for (PlanetSuzakuBlueprint.CanonLocation loc : blueprint.allLocations().values()) {
  1202→            int dx = worldX - loc.x;
  1203→            int dz = worldZ - loc.z;
  1204→            int distSq = dx * dx + dz * dz;
  1205→
  1206→            if (distSq >= TERRAIN_WARP_RADIUS_SQ) continue;
  1207→
  1208→            double dist = Math.sqrt(distSq);
  1209→            double factor = 1.0 - (dist / TERRAIN_WARP_RADIUS);
  1210→
  1211→            int warp = getTerrainWarpForLocation(loc);
  1212→            totalOffset += (int) (warp * factor);
  1213→        }
  1214→
  1215→        return totalOffset;
  1216→    }

  1218→    /**
  1219→     * Compute a small deterministic value-noise variation at (worldX, worldZ).
  1220→     * Bilinear interpolation of a per-cell hash, scaled to ±{@link #NOISE_AMPLITUDE}.
  1221→     * Period = {@link #NOISE_PERIOD} blocks.
  1222→     *
  1223→     * <p>The hash is seeded by {@link DeterministicSeedHandler#CANON_SEED},
  1224→     * so the variation is identical every save. The purpose of this noise is
  1225→     * NOT to mimic natural terrain — it is to break the perfectly-flat plateau
  1226→     * that pure canon warping would produce between canon locations.
  1227→     */
  1228→    static int canonNoiseVariation(int worldX, int worldZ) {
  1229→        int cellX = Math.floorDiv(worldX, NOISE_PERIOD);
  1230→        int cellZ = Math.floorDiv(worldZ, NOISE_PERIOD);
  1231→        int fracX = worldX - cellX * NOISE_PERIOD;
  1232→        int fracZ = worldZ - cellZ * NOISE_PERIOD;
  1233→
  1234→        // Smoothstep interpolation weights
  1235→        double sx = (double) fracX / NOISE_PERIOD;
  1236→        double sz = (double) fracZ / NOISE_PERIOD;
  1237→        sx = sx * sx * (3 - 2 * sx);
  1238→        sz = sz * sz * (3 - 2 * sz);
  1239→
  1240→        // Four corner values in range [0, 2*NOISE_AMPLITUDE]
  1241→        double v00 = noiseHash(cellX,     cellZ);
  1242→        double v10 = noiseHash(cellX + 1, cellZ);
  1243→        double v01 = noiseHash(cellX,     cellZ + 1);
  1244→        double v11 = noiseHash(cellX + 1, cellZ + 1);
  1245→
  1246→        double ix0 = v00 + (v10 - v00) * sx;
  1247→        double ix1 = v01 + (v11 - v01) * sx;
  1248→        double val = ix0 + (ix1 - ix0) * sz;
  1249→
  1250→        // Center around zero: range [-NOISE_AMPLITUDE, +NOISE_AMPLITUDE]
  1251→        return (int) Math.round(val - NOISE_AMPLITUDE);
  1252→    }
  1253→
  1254→    /**
  1255→     * Deterministic hash → value in [0, 2 * NOISE_AMPLITUDE]. Uses a
  1256→     * splitmix64-style mixing of (cellX, cellZ, CANON_SEED) so that
  1257→     * adjacent cells produce decorrelated values.
  1258→     */
  1259→    private static long noiseHash(int cellX, int cellZ) {
  1260→        long h = DeterministicSeedHandler.CANON_SEED;
  1261→        h ^= (long) cellX * 0x9E3779B97F4A7C15L;
  1262→        h ^= (long) cellZ * 0xC2B2AE3D27D4EB4FL;
  1263→        h ^= h >>> 33;
  1264→        h *= 0xFF51AFD7ED558CCDL;
  1265→        h ^= h >>> 33;
  1266→        h *= 0xC4CEB9FE1A85EC53L;
  1267→        h ^= h >>> 33;
  1268→        // Map to [0, 2 * NOISE_AMPLITUDE]
  1269→        return (h & 0xFFFFFFFFL) % (2L * NOISE_AMPLITUDE + 1);
  1270→    }
  1271→
  1272→    /**
  1273→     * Get the terrain warp height for a canon location.
  1274→     * Positive = raise (mountains), Negative = lower (seas/tombs).
  1275→     *
  1276→     * <p><b>Canon fidelity (fact-checked against 仙逆):</b>
  1277→     * <ul>
  1278→     *   <li>恒岳山 (Heng Yue Mountain): the mountain where Heng Yue Sect is
  1279→     *       located. Canon describes it as Zhao Country's largest mountain.
  1280→     *       Raised terrain is correct.</li>
  1281→     *   <li>修魔海 (Sea of Devils): a vast, perilous sea east of Zhao Country.
  1282→     *       Lowered terrain (below sea level) creates ocean.</li>
  1283→     *   <li>朱雀墓 (Suzaku Tomb): underground inheritance site. The entrance
  1284→     *       is on the surface but leads underground. Slight depression is
  1285→     *       appropriate for the entrance area.</li>
  1286→     *   <li>Wang Family Village: "赵国某偏僻小山村" — a remote mountain village.
  1287→     *       Slight elevation fits the "mountain" description.</li>
  1288→     *   <li>藤家城 (Teng Family City): powerful family city in Zhao Country.
  1289→     *       Moderate elevation for a walled city.</li>
  1290→     * </ul>
  1291→     */
  1292→    private static int getTerrainWarpForLocation(PlanetSuzakuBlueprint.CanonLocation loc) {
  1293→        return switch (loc.id) {
  1294→            // Mountainous sect locations — raised terrain
  1295→            case "heng_yue_sect" -> MAX_WARP_HEIGHT; // 恒岳山 — largest mountain in Zhao
  1296→            case "soul_refining_sect" -> 15; // 炼魂宗 — mountain sect
  1297→            case "xuan_dao_sect" -> 15; // 玄道宗 — mountain sect
  1298→            case "luo_he_sect" -> 12; // 洛河门 — sect with spirit veins
  1299→
  1300→            // Settlement cities — moderate elevation
  1301→            case "teng_family_city" -> 10; // 藤家城 — powerful family, elevated city
  1302→            case "tian_shui_city" -> 8; // 天水城 — northern military city
  1303→            case "four_sects_alliance" -> 6; // 四派联盟 — mortal towns
