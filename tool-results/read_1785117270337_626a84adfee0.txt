     6→/**
     7→ * RI Canonical Database — structured query engine for all 630 canon entries.
     8→ *
     9→ * <p>This class bridges the critical gap between the markdown canon documents
    10→ * and the Java runtime. Previously, only the 3 canon-markdown-based engines
    11→ * (Timeline, Ecology, Civilization) and the item-specific HeavenDefyingBead.java
    12→ * existed. The 178 artifacts, 214 techniques, 158 characters, and 80 locations
    13→ * defined in {{@code ri_canon_database.json} had ZERO Java representation.
    14→ *
    15→ * <p>Data source: {{@code ri_canon_database.json} (14,909 lines, 630 entries).
    16→ * <ul>
    17→ *   <li>{@link CanonCharacter} — 158 characters (N01-N160)</li>
    18→ *   <li>{@link CanonLocation} — 80 locations (L01-L80)</li>
    19→ *   <li>{@link CanonArtifact} — 178 artifacts (I01-I178)</li>
    20→ *   <li>{@link CanonTechnique} — 214 techniques (T01-T170 + AT01-09 + VA01-04 + OS01-07 + B01-09 + E01-14)</li>
    21→ * </ul>
    22→ *
    23→ * <p>All data is loaded from the JSON at construction time and cached in
    24→ * typed lists. Query methods provide filtered access by confidence, type,
    25→ * owner, user, location, and free-text search.
    26→ *
    27→ * <p><b>Prime Directive:</b> Every entry traces back to the 3 canon docs
    28→ * (WORLD.md, ITEMS.md, TECHNIQUES.md) with chapter citations. Zero generic
    29→ * fantasy content. Confidence 5 = explicitly attested; 4 = strongly implied;
    30→ * 3 = logically necessary; 2 = derived speculation; 1 = bare conjecture.
    31→ *
    32→ * <p>Per user corrections in SYSTEMS_AUDIT_COMPLETE.md:
    33→ * <ul>
    34→ *   <li>No Allheaven-as-Wang-Lin-antagonist (correction #1)</li>
    35→ *   <li>No 9-9-1 tribulation structure (correction #2)</li>
    36→ *   <li>Suzaku is a planet, not a continent (correction #6)</li>
    37→ *   <li>Heavenly Fate is a planet, not a continent (correction #7)</li>
    38→ *   <li>Essences do not unlock at realm X (correction #5)</li>
